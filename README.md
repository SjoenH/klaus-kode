# Klaus Kode
The "Claude Code killer" CLI harness.

## Før du begynner
- Node.js - https://nodejs.org/en/download
- pnpm - https://pnpm.io/installation
  - (bare en preferanse, npm burde også fungere fint)

## Spoonfeeding

Installer pakker
```bash
pn i
```

Kjør koden
```bash
pn dev
```

Koden finner du i `src/index.ts`.


--- Ekstra exstra ---

Formater og lint koden
```bash
pn fix
```
